Reference Specification

Open Track Sharing Format

Shared backing tracks generated within our apps are completely self-contained. Rather than relying on cloud accounts or central databases, all chord sequences, tempo markers, and rhythm assignments are compressed into URL parameters.

URL Structure

How Shared Track Links Work

When a musician shares a track via link or QR code, the track configuration is deflated with Zlib and encoded into URL-safe Base64:

https://guitarists-collaboration.github.io/guitarstudio?mix=<compressed_track_payload>
  • No accounts: Anyone receiving the link can open the arrangement without registering.
  • Universal compatibility: Opening the link on a device with Guitar Studio installed automatically loads the track into the player.
  • Web fallback: Opening the link on a desktop or unsupported browser directs to the track overview and installation page.

Guitar Studio

Guitar Studio is an Android companion application designed for offline practice, deep fretboard visualization, and multi-track backing playback.

24-Fret Visualization

Displays active chord tones overlaid on scale/mode intervals with dynamic illumination and audio-reactive peak bursts across the entire neck.

  • Chord & scale interval analysis
  • Configurable interval, finger, and note names
  • Audio-reactive note pulsing

Sound Engine & Mixer

Integrated FluidSynth synthesis engine with dual rhythm layers, real-time reverb, chorus, and individual channel faders.

  • Dual rhythm pattern layering
  • Industrial 16-tap drum radar scope
  • Per-bar instrument automation
